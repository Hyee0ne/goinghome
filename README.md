# 손끝 교감

전면 카메라로 손동작을 인식해서 화면 속 보호 동물을 쓰다듬는 웹 프로토타입. PC, 모바일, 태블릿 브라우저에서 동작한다.

## 실행

```bash
npm install
npm run dev          # PC: http://localhost:5173
npm run dev:mobile   # 휴대폰·태블릿: 같은 Wi-Fi에서 https://<PC IP>:5173 접속 (자체 서명 인증서 경고는 '계속'으로 통과)
```

브라우저는 HTTPS나 localhost에서만 카메라를 허용한다. 그래서 휴대폰에서는 `dev:mobile`로 접속해야 한다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/hand.ts` | 카메라 + 손 인식 관리. 손바닥 폄 판정. 워커를 못 쓰면 메인 스레드에서 인식 |
| `src/hand.worker.ts` | MediaPipe Hand Landmarker 추론 워커, 손 2개까지 (화면 그리기를 막지 않게 분리) |
| `src/fur.ts` | 실사 사진 + 털 셰이더(WebGL). 쓰다듬은 털 눕기, 숨쉬기, 눈 깜빡임, 머리·귀 움직임 |
| `scripts/prepare-pet.py` | 투명 배경 사진 → `public/pets/`의 WebP와 털 결 맵 생성. `--eyes`로 눈 반사광을 사진에서 지우고 조각으로 떼어 둔다 (셰이더가 조명 기준 고정 위치에 다시 얹어, 눈동자가 움직여도 반사광은 제자리) |
| `scripts/catchlight.py` | 눈 반사광 지우기·떼어내기 (위 두 스크립트가 같이 쓴다) |
| `scripts/prepare-expression.py` | 같은 사진을 편집한 표정(헥헥, 눈 감기, 귀 젖히기)의 단계들(중간 → 최종)을 부위만 잘라 표정 레이어로 생성 |
| `scripts/prepare-morph.py` | 표정 단계 사이의 움직임(옵티컬 플로우)과 귀 윤곽 거리장을 한 장의 아틀라스로 생성. 표정이 섞이지 않고 움직여서 바뀐다 (OpenCV 필요: `pip install --user opencv-python-headless`) |
| `src/pet.ts` | 펫 그리기(캔버스)와 반응 로직: 냄새 맡기, 쓰다듬기, 놀람, 마음의 거리 |
| `src/pets.ts` | 가상 보호 동물 데이터. 추후 실제 공고 데이터로 교체할 자리 |
| `src/main.ts` | 카메라 손 입력, 좌표 변환, UI, 하트·말풍선 (마우스·터치 입력은 없음) |
| `public/mediapipe`, `public/models` | WASM 런타임과 손 인식 모델 (외부 CDN 없이 자체 호스팅) |

## 실사 표현과 성능

- 사진(`photo`)이 있는 아이(현재 초코)는 WebGL 털 셰이더로 그린다. 사진이 없거나 WebGL을 못 쓰면 캔버스 그림으로 그린다.
- 새 아이를 실사로 추가하려면: 투명 배경 PNG를 준비하고 `python3 scripts/prepare-pet.py <png> public/pets/<id>`를 실행한 뒤, `src/pets.ts`의 `photo`에 눈·코·귀·머리 기준점(잘라낸 사진의 픽셀 좌표)을 적는다.
- 표정은 원본 사진을 편집해 만든 사진을 부위(입, 눈, 귀)별로 섞는다. 원본과 픽셀 단위로 맞아야 하므로 반드시 원본을 편집 대상으로 넣어 만든다 (새로 생성하면 어긋난다).
- 프레임이 계속 40fps 아래로 떨어지면 셰이더 해상도를 자동으로 낮춘다.
- `?debug`로 접속하면 fps, 메인 스레드 시간, 손 인식 시간이 보인다. `?debug=mouse`는 카메라 없이 마우스를 누른 채 움직여 손을 흉내낸다 (Shift를 누르면 대칭인 양손).

## 새 아이 추가하기 (사진 → 실사 동물)

정면을 바라보는 개·고양이 사진 한 장으로 만든다. 원본 사진을 편집하므로 실제 아이의 모습이 유지된다.

```bash
npm run pet:add -- 사진.jpg --id bori --species dog --name 보리 --breed "진도 믹스" --age "1살 추정" --sex 여아 \
  --story "..." --tip "..." --favorite body    # favorite: head | chin | body, 겁 많은 아이는 --shy true
```

1. **배경 지우기** macOS 내장 Apple Vision으로 무료 (윤곽에 남은 배경색도 정리). `--ai-cutout`이면 AI 편집
   `--reference`면 사진은 참고용으로만 쓰고, 같은 아이가 정면을 보는 깨끗한 클로즈업을 새로 만든다 (가장 자연스럽지만 털 길이·무늬가 조금 달라질 수 있다. 약 $0.2 추가)
2. **기준점 찾기** 비전 모델이 눈·코·입·턱·정수리·귀를 찾는다 (사진에 눈금 격자를 얹어 정확도를 높인다)
3. **정면 맞추기** 고개가 기울었으면 두 눈이 수평이 되게 돌린다 (무료). 좌우로 돌아간 얼굴은 `--ai-frontal`로 AI 정면 편집 (외모가 달라질 수 있어 정면 사진을 권장)
4. **얼굴 위주로 자르기** 1086×1448로 맞춘다
5. **앱용 사진** 털 결 맵, 눈 반사광 떼어 두기
6. **표정 2장** 얼굴만 잘라 중간(입 살짝·눈 반쯤·귀 절반)과 최종(입 벌림·눈 감음·귀 젖힘)을 한 장씩. 입·눈·귀는 겹치지 않아 한 장에 같이 바꾼다. AI가 얼굴 크기·위치를 조금 바꾸므로 원본에 맞춰 정렬한 뒤 붙인다
7. **표정 레이어·움직임 아틀라스**
8. **등록** `src/rigs/<id>.json` (앱이 자동으로 불러온다)

기준점이 틀렸으면 `npm run dev` 후 **`/rig.html?id=<id>`** 에서 점을 드래그해 고치고 "앱에 반영"을 누른다 (표정 사진은 다시 만들지 않아 수십 초면 끝난다). 명령어로는 `npm run pet:add -- --id <id> --from prepare`. 표정 사진을 새로 만들려면 `--from expressions --regen`.

중간 결과는 `pets-src/<id>/`, 앱용 에셋은 `public/pets/<id>/`에 생긴다.
필요한 것: Python 3 (Pillow, numpy, scipy, opencv-python-headless), `cwebp`.

이미지 편집과 기준점 찾기는 둘 중 하나로 한다.
- **OpenAI API (권장)**: `.env.local`에 `OPENAI_API_KEY=...`를 넣으면 쓴다 (저장소에 올라가지 않음, 이름에 `VITE_`를 붙이지 말 것). 이미지는 `gpt-image-1.5`, 기준점은 `gpt-5.5`. 품질은 `--quality high|medium|low` (기본 high, **low는 털 무늬가 사라져 쓸 수 없음**), 표정만 따로 `--expr-quality`.
  AI 이미지 생성은 표정 2장뿐이라 사진 한 장에 high 기준 약 $0.3 (1024×1024 $0.133 × 2 + 입력). 기준점 편집 화면에서 고쳐 다시 만드는 건 무료.
- **ChatGPT 구독**: 키가 없으면 Codex CLI(ChatGPT 로그인)와 gpt-image 스킬을 쓴다 (사용량 한도가 있다).

`--until <단계>`로 원하는 단계까지만 돌릴 수 있다 (예: `--until frontal`).

## 교감 규칙

- **손바닥과 다섯 손끝**이 모두 닿는 점이다 (화면에 점으로 보이고, 몸에 닿으면 주황색). 손바닥을 펴서 쓰다듬거나, 손가락을 오므려도 **손끝으로 긁으면** 쓰다듬기로 친다. 주먹만 쥐고 있으면 인식하지 않는다.
- 손끝이 지나간 자리는 털이 가늘게 눕고, **눈가를 만지면** 그쪽 눈을 감는다.
- **양손**으로도 쓰다듬을 수 있다. 손마다 따로 판정하고, 두 손으로 함께 부드럽게 쓰다듬으면 더 좋아한다. 한 손이라도 거칠면 놀란다.
- **개와 고양이는 기분을 다르게 표현한다.** 개는 기분이 좋으면 입을 벌리고 헥헥대고 입맛을 다신다. 고양이는 입을 다문 채 눈을 게슴츠레 뜨고, 가끔 천천히 눈을 감았다 뜬다(고양이 키스). 고양이 표정 사진도 입은 바꾸지 않고 눈과 귀만 만든다. 고양이는 그 대신 기분 좋게 머리를 쓰다듬으면 손 쪽으로 머리를 밀며 비비고(부비부비), 귀를 자주 까딱이고, 기분이 좋으면 귀가 살짝 앞으로 향하고 수염이 펴지며, 턱 밑을 긁으면 개보다 턱을 높이 들고 눈을 게슴츠레 뜬다.
- **적당한 속도**로 움직이면 마음의 거리가 오른다. 너무 빠르면 아이가 놀라서 마음의 거리가 조금 줄어든다.
- **좋아하는 부위**(머리, 턱 밑, 등)를 쓰다듬으면 두 배로 빨리 오른다.
- **겁 많은 아이**는 먼저 코 앞에 손을 가만히 1.6초쯤 내밀어 냄새를 맡게 해줘야 쓰다듬을 수 있다.

감도 조정 값은 `src/pet.ts` 상단(`ROUGH_SPEED`, `STROKE_MIN_SPEED`)과 `update()` 안의 증가 계수(`0.011`)에 있다.
