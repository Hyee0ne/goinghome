# 백로그

손끝 교감에서 정했지만 아직 하지 않은 일. 위에 있을수록 먼저 할 일이에요. 끝나면 지우고, 새로 생기면 알맞은 묶음에 더해요.

## AI로 만들기 · 기회

- **AI 횟수를 서버에서 세기.** 규칙(2026-10-05 확정): 사용자 AI는 하루 1번, 그날 공유하면 1번 더, 매번 광고 필수. 지금은 기기(localStorage)에만 세서 저장소를 지우거나 다른 브라우저를 쓰면 우회할 수 있어요. AI 서버를 만들 때 서버에서 세요.
- **AI 하루 전체 상한.** 사용자당 하루 최대 2번이라도 사용자가 늘면 전체 비용이 늘어요. 사용자 AI 만들기는 한 번에 강아지 약 $0.28, 고양이 약 $0.55가 들고, 웹 보상형 광고 1편 수익은 보통 몇 원~수십 원이라 광고 1편으로 메우기 어려울 가능성이 커요. 하루 전체 생성 수 상한(예: 50번이면 최대 약 $28)이나 광고 여러 편을 검토해요. 광고 계정을 연 뒤 실제 수익을 보고 정해요.
- **실제로 공유했는지 확인하기.** 공유창에서 정말 보냈는지 브라우저가 알려 주지 않아서, 지금은 공유창을 열고 취소하지 않으면 공유한 걸로 쳐요. 공유 링크에 추적 번호를 붙이고, 그 링크로 누군가 들어왔을 때 보상하는 방식을 검토해요.
- **진짜 보상형 광고 붙이기.** 지금은 15초 가짜 화면이에요. 웹은 Google Ad Manager 보상형 광고가 후보이고, 광고 계정과 심사가 필요해요. 사용자 확인 필요.
- **AI 서버 만들기·배포.** 2026-10-03 기준 로컬 품질 검증(`pet:upgrade`)까지만 허락됐어요. 검증이 끝나면 Vercel Python Function + Blob 구조로 만들지 사용자에게 다시 확인해요. 결과를 우리 아이에 덧붙이는 함수(applyUpgrade)와 진행 표시 화면도 함께 만들어요.

- **(뺀 기능) AI로 강아지 앞발 만들기.** 2026-10-03 사용자가 빼기로 했어요. 무료·AI 버전 모두 우리 아이는 '손' 개인기가 없어요. 다시 하게 되면 앞발 사진 1~2장을 참고로 받아요(표정에는 참고 사진을 쓰지 않아요).

## 유기동물 데이터

- **공고 사진 작은 크기로.** 지금 목록은 보호소 원본 사진(장당 약 0.5MB)을 바로 불러와요. 24마리씩 나눠 보여 주지만 휴대폰 데이터가 많이 들어요. 배포 때 목록용 작은 사진을 만들어 두는 방법(받은 사진은 캐시해 매시간 다시 받지 않게)을 검토해요.
- **(보류) 공고 강아지·고양이 자동 실사화.** 2026-10-03 사용자가 보류했어요. 지금은 후보 점수 목록(public/data/candidates.json, 매시간 강아지 100·고양이 50마리, 시도당 후보의 15%까지. 공개는 최대 20마리)까지만 만들어요. 기술 담당이 검토한 방식:
  - 주 1회 맥에서 `npm run shelter:make`: 후보 → 무료 선별(짧은 변 600px 미만, 사람 탐지·여러 마리 제외) → 비전 모델 판정 + 눈·코·턱·귀 좌표(장당 $0.01~0.03, 주 약 $1, 공고별 캐시) → pet-add(Apple Vision 배경 지우기, 표정 AI 없이) → 미리보기 페이지에서 사람이 체크해 확정
  - 결과는 매주 덮어쓰는 고아 브랜치 shelter-data에 두고 배포 때 public/shelter/로 받아요(main에 쌓지 않음). 공고가 끝나면 자동으로 빼요.
  - 이용 조건: 공공데이터포털 이용허락범위 '제한 없음'(출처 표시). 화면에 '보호소 공고 사진으로 만든 모습'을 밝히고 공고로 연결해요. 넓게 운영하기 전에 보호소에 알리기를 권해요.
- **GitHub 비밀값 확인.** 실제 사이트에서 공고가 보이려면 저장소 비밀값 DATA_GO_KR_SERVICE_KEY가 있어야 해요. 없으면 빈 목록이 나와요.
- **입양 사이트 더 찾기.** 지금은 포인핸드, 국가동물보호정보시스템, 카라, 동물자유연대 4곳이에요. 어떤 곳인지 확인하지 못한 사이트(kawa.or.kr, zooseyo.or.kr 등)는 넣지 않았어요.

## 확인할 것

- **휴대폰 실측.** 배경 지우기, 털 결 계산, 녹화, 60fps 유지를 실제 폰(특히 오래된 아이폰)에서 재야 해요. 기술 담당이 시험판 페이지를 준비해 뒀어요.
- **실행 취소 메모리.** 배경 지우기 실행 취소는 8단계(약 32MB)예요. 오래된 폰에서 탭이 다시 열리면 6단계로 줄여요.
- **우리 아이 지우기·이름 바꾸기.** 기기에 저장된 우리 아이를 관리하는 화면이 아직 없어요.
