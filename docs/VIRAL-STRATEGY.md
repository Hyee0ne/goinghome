# 고잉홈 바이럴 전략

2026-10-06, 마케팅 담당 작성. 근거는 `.claude/skills/viral-growth/references/research.md`에 있습니다. 서비스 기간은 약 한 달(~11월 초)입니다.

## 한 줄 전략

**"우리 아이가 내 손에 웃었다"는 놀람을 6초 세로 영상으로 퍼뜨리고, 그 링크를 연 사람이 2초 안에 닮은 보호소 아이를 직접 쓰다듬게 한다. 거기서 바로 "우리 아이도 해 볼래?"로 루프를 다시 돌린다.**

- 공유의 동력은 **웃음과 놀람**입니다. 입양 메시지는 영상이 아니라 **받은 사람의 경험 안**에 둡니다.
- 무기 셋: ① 가입 없음 ② 사진이 기기 밖으로 안 나감 ③ 손으로 쓰다듬는 인터랙션. 이 세 가지는 비슷한 선례(Deep Nostalgia, 독플갱어)에 없던 것입니다.

## 하지 않는 것

- 커뮤니티·카페 인위적 글, 가짜 후기, 부계정 홍보
- 공유 보상(경품, 추첨, 기능 해제). 이미 정한 원칙이기도 하고("신기하면 공유한다"), 광고 표기 의무 문제도 있습니다.
- 숫자 부풀리기. 카운터는 실제 집계만 씁니다.
- 슬픔·안락사를 앞세운 문구
- 공공데이터 외의 입양 사이트 언급
- 사용자 사진을 서버에 올리는 공유 방식

## 루프와 지표

```
[A] 내 아이 사진 넣기 → [B] 웃는 결과 → [C] 영상 공유 → [D] 카톡 미리보기 클릭
     ↑                                                        ↓
[H] 다시 공유 ← [G] 내 아이 만들기 ← [F] "너도 해 볼래?" ← [E] 닮은 보호소 아이 쓰다듬기
                                                              ↓
                                               [I] 공고 보기 · 보호소 전화 (입양 행동)
```

| 지표 | 뜻 | 왜 |
|---|---|---|
| **K = 공유율 × 받은 사람 전환율** | 만든 사람 1명이 데려오는 새로 만드는 사람 수 | 1을 넘으면 스스로 큰다 |
| **사이클 타임** | 공유 → 받은 사람이 만들어 다시 공유까지 | K보다 효과가 크다 |
| C/B 공유율 | 결과를 본 사람 중 공유한 비율 | 결과물 매력 |
| E/D 체험률 | 링크를 연 사람 중 쓰다듬은 비율 | 랜딩 속도 |
| G/E 만들기 전환율 | 쓰다듬은 사람 중 만들기 시작 비율 | 초대 문구·시점 |
| **I 입양 행동 수** | 공고 보기·전화 버튼 누른 수 | 우리가 존재하는 이유 |

측정 방법: 공유 링크에 `gen`(몇 번째 세대)과 `src`(pet/site/adopt)만 붙이고, 쿠키 없는 무료 집계(GoatCounter 또는 Cloudflare Web Analytics)로 위 단계 이벤트를 셉니다. 개인 정보와 사진 정보는 넣지 않습니다.

## 지금 상태 점검 (2026-10-06, feature/viral 기준)

| 단계 | 지금 | 문제 |
|---|---|---|
| D 미리보기 | index·make·adopt 모두 **OG 태그 없음** | 카톡에 보내면 제목·사진 없는 링크만 보인다. 가장 큰 구멍 |
| C 영상 형식 | 720×960 (3:4), mp4 우선 | 릴스·쇼츠·스토리(9:16)에서 위아래가 비거나 잘린다 |
| C 워터마크 | 왼쪽 아래 '🏠 고잉홈' | 릴스·틱톡 하단 UI에 가려지는 자리. 주소가 없어 재공유 시 출처가 사라진다 |
| C 엔드카드 | 1.4초, 닮은 보호소 아이 | 좋음. 6초 중 1.4초는 길어서 1초 안팎으로 줄여 본다 |
| E 받은 사람 | `?from=share` → 닮은 보호소 아이, 20초 뒤 초대 | 방향은 맞다. 20초는 길 수 있으니 첫 반응 직후로 시험 |
| G 만들기 | make.html | **카톡 인앱 브라우저 대응 없음.** 카메라·저장·공유가 막힐 수 있다 |
| C 인스타 | 공유 시트 → 실패 시 다운로드 + 링크 복사 | 인스타로 바로 가는지 실기기 미확인. "저장 후 올리기" 안내가 없다 |
| I 입양 행동 | 상세의 보호소 전화·공고 | 공유 직후에 나오는 "혼자 하는 다음 행동"이 없다 |
| 측정 | 없음 | K를 알 수 없다 |

## 우선순위

### P0: 이번 주 (10/6~10/12) — 루프의 구멍 막기

1. **OG 태그와 미리보기 이미지** (서비스)
   - 세 페이지에 og:title·og:description·og:image(JPG 800×400)를 넣습니다.
   - 공유 링크용 문구 예: "손끝으로 쓰다듬어 주세요 🐾 · 고잉홈".
   - 이미지는 웃는 고퀄 보호소 아이 얼굴로 하고, URL에 `?v=1`을 붙여 바꿀 수 있게 합니다.
2. **영상 9:16 + 세이프존** (기술: 녹화 크기 / 서비스: clipOverlay)
   - 720×1280으로 녹화합니다.
   - 워터마크를 위쪽 1/3 아래 가운데에 작게 둡니다(고잉홈 + 주소).
   - 첫 프레임부터 움직이게 합니다(웃음이나 헥헥이 0초에 시작).
   - 자막 한 줄: "우리 ○○ 쓰다듬었더니…"
3. **카톡 인앱 브라우저 → 외부 브라우저** (서비스)
   - make.html과 녹화·저장 단계에서 UA로 KAKAOTALK을 감지하면 "브라우저로 열기"(`kakaotalk://web/openExternal?url=`)를 띄웁니다.
   - 쓰다듬기 체험(E)은 인앱에서도 되게 둡니다.
4. **익명 단계 집계** (서비스)
   - `gen`·`src` 파라미터를 붙이고, 이벤트 B·C·D·E·G·I를 셉니다.
   - 도구 선택은 사용자 확인이 필요합니다.
5. **인스타 대체 흐름** (서비스)
   - 파일 공유가 안 되면 "영상을 저장했어요 → 인스타 열고 릴스/스토리에 올려 주세요" 안내를 띄웁니다.
   - 아이폰과 안드로이드 실기기에서 확인합니다.

### P1: 둘째 주 (10/13~10/19) — 전환율 올리기

6. **받은 사람 초대 시점 시험**: 20초와 첫 반응 직후(약 6~8초)를 집계로 비교합니다.
7. **"닮은 이유" 한 줄**: "털색과 귀가 ○○랑 닮았어요". 독플갱어에서 공유 포인트였던 부분입니다.
8. **공유 직후 혼자 하는 행동** (슬랙티비즘 방지): 공유가 끝나면 "○○랑 닮은 친구 공고 보기 · 보호소 번호"를 보여 줍니다.
9. **입양 3단계 안내 + 공고 마감 D-n**: 실제 공고 기간만 씁니다. 입양을 망설이는 이유 2위가 "절차 정보 부족"(27.8%)입니다.
10. ~~카톡 공유 SDK~~: 하지 않음 (2026-10-06 사용자 결정). 카톡은 웹 공유(`navigator.share`)와 OG 미리보기로 갑니다.
11. **공고별 정적 미리보기 페이지**: 보호소 아이 공유("이 아이 입양 정보")가 그 아이 얼굴로 미리보기되게, 빌드 때 아이별 HTML과 OG 이미지를 만듭니다(GitHub Actions).

### P2: 셋째~넷째 주 (10/20~11/2) — 진짜 사람들이 퍼뜨리게

12. **SNS를 운영하는 보호센터에 영상 무료 제공**
    - 그 센터 아이(고퀄)의 움직이는 쓰다듬기 영상 몇 개를 만들어, 센터 공식 계정에 올릴 수 있게 드립니다.
    - 연락 초안은 마케팅이 쓰고, 연락은 사용자가 합니다.
    - 공공데이터 공고 아이만 다룹니다.
13. **보도자료**
    - 동물 전문지와 IT 매체에 보냅니다.
    - 포인트: "사진이 폰 밖으로 안 나가는 웹", "공공데이터 공고와 연결", "손으로 쓰다듬는다".
14. ~~10/17~18 서울 동물행복페스타 현장 참여~~: 하지 않음 (2026-10-06 사용자 결정).
15. **새로 공유할 이유**
    - 핼러윈(10/31) 소품 하나 같은 작은 시즌 요소를 넣습니다.
    - 매주 새로 들어오는 실제 공고 아이를 "이번 주 새 친구"로 보여 줍니다.

## 문구 기준

- 영상과 공유 글은 **밝게**: "우리 ○○ 손끝으로 쓰다듬었더니 웃었어요 🐾"
- 받은 사람 화면은 **한 마리**: "○○랑 닮은 △△가 가족을 기다려요 (10월 ○일까지)"
- 안심 문구는 첫 화면에: "사진은 내 폰 밖으로 나가지 않아요"
- 출처 표기: 농림축산식품부 국가동물보호정보시스템
